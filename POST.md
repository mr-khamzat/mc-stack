# 🏠 HA Home Bot — Умный дом в Telegram и браузере

> Бесплатный open-source проект. Python + один HTML файл. Работает на любом VPS от $3/мес.

---

## Что это такое?

Телеграм-бот плюс мобильное веб-приложение (Mini App) для управления умным домом через Home Assistant.

Весь проект — это два файла: `ha_bot.py` (бот и сервер) и `index.html` (интерфейс).
Никаких фреймворков, никакого node.js, никаких сложных деплоев.

📦 Репозиторий: [github.com/mr-khamzat/mc-stack](https://github.com/mr-khamzat/mc-stack)

## Что умеет

### 💡 Управление светом
Включить, выключить или разом погасить весь свет — прямо из Telegram или с телефона.
Новые лампочки из Home Assistant добавляются автоматически — ничего прописывать вручную не нужно.

**Что можно менять:** список ламп, иконки, название каждого выключателя.

---

### ⚡ Электроэнергия
Показывает сколько ватт потребляет дом прямо сейчас, сколько уже потрачено денег сегодня
и какой счёт ждёт в конце месяца (прогноз). Если подключён трёхфазный ввод — видны все три фазы.

**Что можно менять:** entity_id счётчика, тариф (руб/кВт·ч), пороговое значение для алертов.

---

### 🌡️ Климат
Температура и влажность в комнате, управление тёплым полом — поднять/опустить температуру
кнопками. График температуры за последние 24 часа.

**Что можно менять:** какую комнату показывать, entity_id климатики и датчика.

---

### 🌤️ Погода
Текущая погода и прогноз на 3 дня без ключей и регистрации (Open-Meteo API).
Данные кешируются на 10 минут чтобы не спамить запросами.

**Что можно менять:** координаты города (широта/долгота в коде), часовой пояс.

---

### 🕌 Намаз
Расписание пяти молитв с обратным отсчётом до следующей. Времена берутся из
Home Assistant (input_datetime сущности) — настраиваются один раз и меняются автоматически.
Алерт в Telegram за 10 минут до молитвы.

**Что можно менять:** entity_id для каждого времени намаза, включить/выключить алерт.

---

### 📺 Телевизор
Включить, выключить, поставить на паузу, изменить громкость — прямо из Telegram.
Видно что сейчас играет (приложение, название).

**Что можно менять:** entity_id телевизора (TV_EID в коде).

---

### 🤖 Пылесос
Запустить уборку, отправить на зарядку, проверить статус робота-пылесоса.

**Что можно менять:** entity_id пылесоса.

---

### 👪 Семья — присутствие
Видно кто дома, кто уехал — по геолокации из HA (person.* сущности).
Все члены семьи определяются автоматически — не нужно ничего прописывать.

**Что можно менять:** ничего (автоматически находит всех person.* в HA).

---

### 🎬 Сцены
Готовые сценарии: «Спать» (выключить весь свет), «Уходим» (свет + TV), «Кино» (приглушить),
«Вечер» (мягкий свет). Можно создавать свои сцены через Mini App.

**Что можно менять:** список действий в каждой сцене, добавлять новые сцены.

---

### 📹 Камеры Frigate
Снимок с камеры прямо в Telegram одной кнопкой. Список последних событий детекции
(кто и когда попал в кадр). Просмотр клипов. Работает если в HA установлен аддон Frigate.

**Что можно менять:** entity_id камер, включить/выключить через `/devices`.

---

### 📞 Звонки (WebRTC P2P)
Аудио и видео звонки между пользователями приложения — напрямую, без посредников.
Сервер только помогает установить соединение (передаёт сигнал), сам медиа-трафик
идёт напрямую между устройствами. Входящий звонок — push-уведомление на телефон.

Для звонков через разные сети (например дом → мобильный интернет) нужен TURN-сервер
(coturn, установка описана в README).

**Что можно менять:** настройки TURN (SERVER_IP, TURN_SECRET в .env).

---

### 💬 Чат
Текстовые сообщения, фотографии и голосовые сообщения между пользователями приложения.
История за 48 часов. Уведомления в реальном времени.

---

### 📸 Галерея
Общий фотоальбом для всех членов семьи. Загружать фото можно прямо из приложения.

---

### 🔔 Напоминания
Установить напоминание на конкретное время — придёт push-уведомление на телефон
(даже если приложение закрыто, если разрешены уведомления в браузере).

---

### 🛒 Список покупок
Список покупок из Home Assistant (todo список). Отметить выполненным прямо в Telegram.
Можно назначить товар конкретному члену семьи.

---

### 🔔 Алерты
Автоматические уведомления в Telegram:
- Потребление превысило порог (например 3 кВт)
- Температура вышла за диапазон (слишком жарко/холодно)
- Кто-то пришёл домой или ушёл
- Потеря интернета
- Событие на камере (детекция человека Frigate)
- Напоминание о намазе за 10 минут
- Утренний брифинг в 8:00 (погода, энергия, намаз)

**Что можно менять:** пороги, часы тишины, включить/выключить каждый тип алертов.

---

### 🧠 AI Ассистент
Чат с Claude AI прямо в Telegram — задать вопрос, попросить помочь с автоматизацией.
Требует установленный Claude CLI на сервере.

---

### 📱 PWA — устанавливается на телефон
Mini App можно добавить на главный экран как обычное приложение — иконка, сплэш-скрин,
работает без браузера. Поддерживает тёмную и светлую тему, живой фон меняется по времени суток.

---

### 📊 Сервер
Мониторинг самого сервера: CPU, RAM, диск, uptime — прямо в приложении.

---

### ☀️ Ночной режим
Автоматическое снижение яркости и отключение уведомлений в ночное время.

---

### 🔐 Система пользователей
- **owner** — главный администратор (ADMIN_ID из .env)
- **admin** — полный доступ, добавляется через ссылку-приглашение `/invite admin`
- **viewer** — только просмотр, не может управлять устройствами
- **guest** — ограниченный гость Mini App (видит только то что ему разрешили)

Новый пользователь пишет боту `/start` → администратор получает запрос и одним нажатием
выдаёт роль.

---

### 🔄 Real-time обновления (SSE)
Состояние приложения обновляется в реальном времени без перезагрузки страницы.
Изменилось состояние устройства в HA → сразу отображается в приложении у всех пользователей.

Технически: бот подключается к WebSocket HA и транслирует изменения в Mini App
через Server-Sent Events (SSE) — однонаправленный поток событий от сервера к браузеру.

---

### 💾 Хранение данных
Все настройки (устройства, сцены, алерты, пользователи) хранятся в SQLite.
Каждую ночь в 3:00 автоматически делается резервная копия и отправляется в Telegram.

---

### 🔒 SSL и безопасность
- Ежедневная проверка SSL сертификатов с уведомлением за 14 дней до истечения
- Авторизация Mini App через Telegram initData HMAC (стандарт Telegram)
- Веб-сервер слушает только `127.0.0.1` — снаружи доступен только через nginx

## Технический стек (кратко)

| Компонент | Технология |
|-----------|-----------|
| Бот | Python 3.11, aiogram 3.x |
| Веб-сервер | aiohttp (встроен в ha_bot.py) |
| База данных | SQLite |
| Интерфейс | Один HTML файл, ванильный JS |
| Push уведомления | Web Push API (VAPID) |
| Звонки | WebRTC P2P |
| Real-time | Server-Sent Events (SSE) |
| Погода | Open-Meteo (бесплатно, без ключа) |
| Графики | matplotlib (PNG в Telegram) |

## Требования для запуска

- VPS Ubuntu 22.04/24.04 (или Proxmox LXC) — от 512 MB RAM
- Python 3.11+
- Home Assistant с Long-Lived Access Token
- Telegram Bot Token (создать у @BotFather)
- HTTPS домен для Mini App (Cloudflare Tunnel — бесплатно, или nginx + Let's Encrypt)

Полная инструкция по установке — в [README.md](README.md).

## Структура файлов

```
/opt/ha-bot/
├── ha_bot.py          ← весь бэкенд: бот + веб-сервер
├── .env               ← конфиг (токены, URL)
├── ha_bot.db          ← база данных SQLite
└── webapp/
    ├── index.html     ← весь фронтенд Mini App
    ├── manifest.json  ← PWA манифест
    └── sw.js          ← Service Worker (push уведомления)
```

## Быстрый старт

```bash
git clone https://github.com/mr-khamzat/mc-stack.git /tmp/mc-stack
cp -r /tmp/mc-stack/bot /opt/ha-bot
cd /opt/ha-bot && python3 -m venv venv && source venv/bin/activate
pip install aiogram aiohttp python-dotenv psutil matplotlib pywebpush websockets cryptography
cp webapp/.env.example .env
nano .env   # вписать BOT_TOKEN, ADMIN_ID, HA_URL, HA_TOKEN, WEBAPP_URL
python3 ha_bot.py
```
